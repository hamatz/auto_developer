## 🌟 ハイライト (Overview)

Auto Developer v0.2.0 は、AI エージェントによる自律的なソフトウェア開発において、**「AIの自己申告を信じず、外部の客観的検証と物理的な安全性で品質を保証する」** ための耐障害性・セキュリティ・復旧基盤を完成させた大型マイルストーンリリースです。

これまでの 4 つの実証実験（Pilot 01 〜 Pilot 04）を通じ、以下の 4 大能力を実データ・障害注入試験によって完全に証明しました：

1. **Pilot 01 (自律開発)**: `PLAN.md` に基づく複数タスクの自律実装と確定コミット
2. **Pilot 02 (安全修正)**: 既存コードへの修正と、保護された独立受入テストの回帰ゼロ達成
3. **Pilot 03 (失敗対応)**: 一時障害のリトライ回復、および継続的失敗時の即時遮断（Fail-Fast）と隔離（Quarantine）
4. **Pilot 04 (クラッシュ復旧)**: プロセス突然死（SIGKILL）からのトランザクショナルな Git・JobState・証跡復元と完全な冪等性

## 🚀 主な新機能・改善点

### 1. トランザクショナルなクラッシュ復旧基盤 (`auto-dev recover`)
夜間実行中にマシン停止や SIGKILL 等でプロセスが強制終了された場合でも、作業成果を失わず安全に再開できる復旧エンジンを実装しました。

- **`inspect` (診断)**:
  - Git HEAD、作業ツリー差分、Evidence Store（暗号的証跡）、JobState を相互照合。
  - 「Maker実行中中断」「検証直後中断」「Gitコミット直後中断」「Quarantine処理中中断」の 4 つの境界クラッシュ状態を正確に診断。
- **`plan` (計画)**:
  - 破壊的コマンドを実行する前に、適用予定のアクション（作業退避、ロールバック、状態前進など）を安全に提示。
- **`apply` (適用)**:
  - `fcntl.flock(LOCK_EX | LOCK_NB)` によるプロセス排他制御を全処理中保持し、TOCTOU 競合や多重復旧を物理遮断。
  - コミット前の仕掛かり成果物は隔離ブランチおよび tar スナップショットへ退避。
  - Git コミット確定済みのタスクは二重コミットせず JobState を前進回収。
  - 2回目実行時の完全な冪等性（`Resulting State: UNCHANGED`）を保証。

### 2. 秘密情報漏洩の物理的排除と安全な Quarantine
失敗した作業を後から人間が確認・再利用できるように保全しつつ、漏洩リスクを徹底排除しました。

- **Git 隔離コミットの厳格化**:
  - 隔離ブランチ（`quarantine/...`）へのステージングを `git add -u`（追跡済みのみ）に限定。`.env` や秘密鍵などの未追跡ファイルが誤って Git 履歴に残る事故を防止。
  - 追跡済みファイルに対しても `sanitize_staged_changes()` による正規表現スキャンを実施し、API キー等が書き込まれていた場合はステージを強制解除。
- **Manifest 再帰走査 & SHA-256 全件照合**:
  - サブディレクトリ内の全ファイルを走査し、SHA-256 ハッシュを記録した Manifest を作成。
  - `job_id`, `task_id`, `checkpoint` の 3 重必須照合により、別ジョブや古いアーカイブの誤採用を完全排除。

### 3. 改ざん防止監査証跡 (Evidence Store)
- Git Tree SHA & Spec SHA を拘束する暗号トークンを発行し、検証未通過コードの本線コミットを物理的に防止。
- 全試行履歴（`attempts`）、テスト実行ログ要約、Checker の判定メタデータを監査レコードに保存。
- コミット直後クラッシュ時にも監査証跡を欠落させず、状態遷移を明示。

### 4. 開発者意思決定を支える Morning Brief
- 朝起きた開発者が 1 分で状況を判断できるレポートフォーマット：
  - エグゼクティブサマリー、監査テーブル、隔離ブランチ名、退避アーカイブパス。
  - その場でワンクリック実行できる安全な復旧コマンド（`Run/Verify Dual Commands`）の提示。

### 5. CLI & プラグインエコシステム (`auto-dev`)
- 単一の CLI コマンド `auto-dev` として提供：
  - `auto-dev run` / `auto-dev --dry-run`
  - `auto-dev init`（プロジェクト初期化・規律ファイル配置）
  - `auto-dev recover inspect / plan / apply`
- Google Antigravity プラグインとしての統合。
