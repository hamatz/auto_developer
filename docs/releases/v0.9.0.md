# Auto Developer v0.9.0

**Release Date**: 2026-11-23
**Tag**: `v0.9.0`

## Highlights

- **OS Sandbox Hardening (`SBX-7`, `SBX-8`)**:
  - macOS `sandbox-exec` now supports symlinked Python executables (such as GitHub Actions `setup-python`) using minimal `literal` symlink and parent metadata traversal rules without weakening home or repository read denials.
  - Linux `bwrap` `/opt` isolation tests exclude mounted Python prefix paths and their ancestor directories.
- **Index & Secret Protection (`GATE-9`, `GATE-10`)**:
  - `verify-step` computes working tree SHAs using a temporary `GIT_INDEX_FILE` so untracked files are never staged in the real index.
  - `init` / `teams init` add `.env`, `.env.*`, and `!.env.example` to `.gitignore`, and `verify-step` / `commit-step` / `run` reject uncommitted `.env*` and private key files with `SECRET_FILE_IN_COMMIT:`.
- **Developer Experience & Release Readiness (`DX-1`, `DX-3`, `DX-4`, `DX-9`, `REL-2`, `REL-5`)**:
  - `verify-step --checkpoint` resolves symbolic refs (e.g. `HEAD`) to 40-character commit SHAs in Evidence, reviews, and metrics events.
  - Added `scripts/gen_cli_reference.py` and generated `docs/cli.md` with automated sync verification.
  - Added `examples/two-teams/` and automated execution tests for `README.md` and `README.en.md` quickstart blocks.
  - Removed developer-specific local paths from tracked files and added a tracked-file audit test.
  - Aligned version metadata to `0.9.0`.
